# Git y GitHub

Apuntes y prácticas para aprender **Git** (control de versiones) y **GitHub** (alojar y compartir repositorios), pensados para usarlos con cualquier lenguaje de programación.

!!! info "Cómo está organizado"
    Cuatro unidades, de menos a más: **primeros pasos**, **ramas**, **GitHub y SSH** y **flujo de trabajo profesional**. Cada unidad tiene su teoría y, debajo, sus ejercicios, que se desbloquean al marcar la unidad como leída.

| Unidad | Contenido |
|---|---|
| [U1 · Primeros pasos](u01/index.md) | Conceptos, instalación, `init`, `add`, `commit`, `log`, `.gitignore` |
| [U2 · Ramas](u02/index.md) | `branch`, `switch`, `merge`, conflictos y `stash` |
| [U3 · GitHub y SSH](u03/index.md) | Remotos, `push`, `pull`, `clone`, claves SSH |
| [U4 · Flujo profesional](u04/index.md) | Commits profesionales, `rebase` y Pull Requests |
| [Chuleta de comandos](chuleta.md) | Los comandos más usados en una página |

!!! tip "Para empezar"
    Si nunca has usado Git, empieza por [Conceptos](u01/conceptos.md). Si ya lo conoces, la [chuleta](chuleta.md) te sirve de repaso.

!!! tip "¿Quieres ir más allá?"
    Activa el interruptor **Avanzado** de la cabecera para ver el [material avanzado](avanzado/index.md): reescribir la historia, investigar errores, trabajo en equipo y automatización.
