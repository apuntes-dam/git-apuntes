# U1 · Primeros pasos con Git

Un repositorio local, sus primeros commits y cómo consultar y deshacer cambios con seguridad.

## Teoría

1. [Conceptos](conceptos.md): qué es Git y las tres áreas de trabajo.
2. [Instalar y configurar](instalar.md): Git, identidad y terminal.
3. [Tu primer repositorio](primer-repo.md): `init`, `add`, `commit`, `log`, `diff`, `.gitignore`.

## Antes de empezar: qué debes dominar

* Qué es un repositorio, un commit y una rama.
* Diferencia entre directorio de trabajo, área de preparación y repositorio.
* El ciclo `status` → `add` → `commit`.
* Cómo consultar el historial y descartar cambios sin perder trabajo.
