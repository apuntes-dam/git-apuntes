# A5 · Automatizar y configurar

Lo que haces **todos los días** con Git se puede **automatizar**: comprobar el código **antes de cada commit**, exigir **mensajes con un formato**, abreviar comandos largos con **alias**, **configurar** Git a tu medida, **limpiar** lo que sobra, **exportar** el proyecto y dejar que un servidor **pruebe cada cambio**. Aquí aprendes las herramientas.
