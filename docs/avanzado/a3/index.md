# A3 · Investigar la historia

El historial de un proyecto es un **archivo de lo que ha pasado**, y casi siempre se consulta con una pregunta concreta: «¿**quién** cambió esta línea?», «¿**cuándo** apareció este error?», «¿**qué** se tocó en este archivo?». Aquí aprendes a **filtrar el `log`**, a buscar **cuándo apareció un texto**, a ver **quién escribió cada línea** con `blame` y a **encontrar el commit que rompió algo** con `bisect`, que lo hace casi solo.
