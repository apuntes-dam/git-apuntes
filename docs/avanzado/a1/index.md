# A1 · Reescribir y recuperar la historia

Un error en Git casi nunca es el final: casi todo se puede **corregir, deshacer o recuperar**. Aquí aprendes las herramientas para **enmendar** un commit, **volver atrás** de tres formas distintas, **deshacer sin reescribir**, **recuperar lo que parecía perdido** con `reflog`, **copiar un commit** a otra rama y **publicar con cuidado** cuando has cambiado una historia ya subida.
